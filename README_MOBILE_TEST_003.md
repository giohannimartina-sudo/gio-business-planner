# GIO Business Planner PRO – Mobile TEST 003

Gebouwd vanaf: `GIO_Business_Planner_PRO_v2.1_RC_KM_SLIM_UPDATE(1)`.

## Behouden
- Desktoplayout en bestaande functies
- Cloud, synchronisatie en back-up
- Planning, klanten, projecten, uren, materiaal, uitgaven, betalingen
- Offertes, facturen, archief, balans en export
- Bestaande lokale gegevensstructuur

## Mobiel
- Eén onderste navigatie: Vandaag, Planning, Projecten, Werkboek, Meer
- Normale knopgroottes
- Compacte kaarten en formulieren
- Snelle actie-overlay
- Alle bestaande functies bereikbaar via Meer
- KM / Reis is zichtbaar in Meer en Snelle actie

## Nieuw
- Werkboek: aanmaken, bewerken, verwijderen, klaarzetten, zoeken, koppelen aan klant/project
- Gekoppelde notities zichtbaar in Projectkaart PRO
- Voorraad: foto, naam, categorie, locatie, eenheid, aantallen, minimum, inkoop/verkoop, zoeken en mutaties

## Belangrijke reparatie
De ongeldige HTML-constructie waarbij inline KM-code in een `<script src="...">` stond, is gesplitst in geldige scriptblokken. Dit voorkomt dat functies ontbreken of code verkeerd wordt verwerkt.
